### 🚀 Featured Projects

#### ⚙️ Codexion — Multithreaded Simulation in C

A concurrent simulation designed to explore resource management, synchronization, and scheduling.

**Key concepts:**
- POSIX threads and mutexes
- Condition variables and synchronization
- FIFO and Earliest Deadline First (EDF) scheduling
- Priority queues and heap data structures
- Deadlock prevention and thread coordination

#### 🧠 MiniML — Machine Learning From Scratch

An educational machine learning library built in Python to understand how ML algorithms work internally.

**Focus areas:**
- Linear and logistic regression
- Gradient descent and optimization
- Decision trees and neural networks
- Data preprocessing and evaluation metrics

#### 💳 Credit Card Fraud Detection

A machine learning project exploring fraudulent transaction detection using real-world-style financial data.

**Focus areas:**
- Exploratory data analysis
- Handling imbalanced datasets
- Feature engineering
- Classification models and performance evaluation
